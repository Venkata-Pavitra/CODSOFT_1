Tic Tac Toe Game 

📌Project Description

   This project is a simple Tic-Tac-Toe game developed using Python as part of my CodSoft Artificial Intelligence Internship.

  The game allows a player to play Tic-Tac-Toe against the computer through the terminal.

✨Features

- Player vs Computer gameplay

- 3 × 3 Tic-Tac-Toe board

- Player uses X

- Computer uses O

- Validates player moves

- Prevents already occupied positions

- Detects winning conditions

- Detects draw conditions

- Displays the game result

🛠️Technologies Used

- Python
