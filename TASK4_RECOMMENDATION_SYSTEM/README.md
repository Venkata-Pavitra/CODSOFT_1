Movie Recommendation System

📌Project Description

  This project is a simple movie recommendation system developed using Python as part of my CodSoft Artificial Intelligence Internship.

  The system uses the information available about each movie, such as its description and genre, to identify similar movies. It uses a content-based filtering approach to generate recommendations.

✨Features
- Recommends movies based on the movie selected by the user.
  
- Uses movie descriptions and genres to find similar movies.

- Provides multiple movie recommendations.

- Uses TF-IDF to process text data.

- Uses Cosine Similarity to calculate the similarity between movies.

- Gives recommendations based on the similarity score.

- Provides a simple and easy-to-use system.

🛠️Technologies Used
- Python

- Pandas

- Scikit-learn

- TF-IDF Vectorization

- Cosine Similarity
